# Fallout – Compagnon de jeu

Application compagnon (PWA mobile, en français) pour jouer au jeu de société *Fallout : le jeu de plateau*. Elle couvre la découverte du jeu, la mise en place, les actions du tour, le combat, les niveaux, les conditions de victoire et un glossaire. Elle permet aussi de jouer en **coopération**.

En ligne sur GitHub Pages : https://ghomerr.github.io/fallout-boardgame-companion/
